**Question:** Which definition is closer to the available reference across participants?

**Dataset/sample:** Overall: 17 participants; strict all-method common-reference beats only.

**Source data:** [F02_HeartCycle_B_reference_accuracy.csv](fig02_heartcycle_b_reference_accuracy.csv) and the canonical tables identified in the calculation.

**Calculation:** Each restrained grey circle is one participant median absolute detected-minus-reference timing error; the black diamond and horizontal bar show the across-participant median and IQR. A horizontal counterpart to the requested algorithm-on-X layout is used because 10/13 long algorithm definitions remain readable without rotation. In ReBeat, right-pointing boundary markers identify observations beyond the main linear range and the inset displays every participant on the full linear range.

**Axes:** Y: B-point algorithm definition. X: participant median absolute reference timing error (ms).

**Result:** The lowest displayed across-participant median was B8 in Overall (12.59 ms). Coverage and excluded reference beats are reported separately.

**Interpretation:** Lower error supports closer correspondence to this specific reference, while the participant dots show heterogeneity.

**Limitation:** HeartCycle ECHO and ReBeat expert annotations are different reference types; expert ICG annotations are not independent ECHO. Median error alone does not establish a universal winner.
