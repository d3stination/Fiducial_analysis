**Question:** Are definitions systematically early or late, and do large tails occur?

**Dataset/sample:** 22 participants, 433 strict common-reference beats, Cognitive workload.

**Source data:** [F03_ReBeat_X_signed_reference_error_cognitive_workload.csv](fig03_rebeat_x_signed_reference_error_cognitive_workload.csv) and the canonical tables identified in the calculation.

**Calculation:** Signed error = detected time − reference time. Every algorithm uses identical hybrid bin edges and the same count scale over the complete symmetric range (±880 ms). The common symmetric-log x-axis is linear from −180 to +180 ms and logarithmically compressed outside that interval, so central structure and every tail observation remain visible without miniature insets.

**Axes:** X: signed detected-minus-reference error (ms), common symmetric-log scale with a labelled linear centre. Y: heartbeats (count). Blue indicates earlier-than-reference and muted red later-than-reference; the dark vertical line is zero error.

**Result:** Most negative median: X9 -164.00 ms; most positive median: X10 15.03 ms; largest P95 absolute error: X4 448.00 ms (numerical statistics are kept in this report, not the panels).

**Interpretation:** The sign separates systematic early/late localisation from the magnitude of tail errors.

**Limitation:** Repeated beats are clustered within participants and histograms are descriptive. The nonlinear display scale changes visual spacing but not bin counts; common edges/scales preserve algorithm comparability. No tolerance-exceedance percentage is calculated because no approved threshold exists.

**RQ1 contribution:** Reveals systematic timing bias and occasional large errors hidden by an unsigned median alone.
